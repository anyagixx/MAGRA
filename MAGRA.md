# MAGRA

MAGRA is a Reasonix-based AI coding agent project that integrates:

- MyGRACE for index-first architecture, skills, planning, execution, and verification.
- RTK for token-optimized shell command output and savings telemetry.
- SNARC for local, salience-gated project memory.

Reasonix remains the imported base runtime during Phase-1. The existing
`reasonix` and `dsnix` command aliases are preserved for compatibility, while
`magra` is added as the MAGRA command alias.
